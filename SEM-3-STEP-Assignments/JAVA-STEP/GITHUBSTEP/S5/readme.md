# Week 5 – Java Arrays and Methods

**Course:** STEP SEM-3  
**Assignment Category:** Category C  
**Language:** Java

## Topics Covered

- Creating and modifying arrays
- Arrays passed by reference
- Strings and nested loops
- Finding minimum, maximum, and spread
- Two-dimensional arrays
- User-defined methods and method reuse
- Method overloading
- Static methods
- Constructors and encapsulation
- `Comparable` interface
- Sorting objects using `Arrays.sort()`

## Programs

| Program | Problem Name | Concepts |
|---|---|---|
| Q1 | Fantasy Team Score Multiplier | Arrays and pass by reference |
| Q2 | Duplicate Player Pick Checker | Strings and nested loops |
| Q3 | Top Performer Tracker | Loops and min/max tracking |
| Q4 | Match Day Grid Analyzer | 2D arrays and helper methods |
| Q5 | Fantasy League Auto-Draft Ranking Engine | OOP, method overloading, and sorting |

## Files

- `Main.java` – Fantasy Team Score Multiplier
- `Main2.java` – Duplicate Player Pick Checker
- `Main3.java` – Top Performer Tracker
- `Main4.java` – Match Day Grid Analyzer
- `Main5.java` – Fantasy League Auto-Draft Ranking Engine

## How to Compile and Run

Compile a program:

```bash
javac Main.java
```

Run it:

```bash
java Main
```

For the other programs, replace `Main` with the corresponding class name, such as `Main2`, `Main3`, `Main4`, or `Main5`.

## Objective

To practise Java arrays, methods, logical problem-solving, and object-oriented programming through the implementation of fantasy sports and match-analysis problems.
